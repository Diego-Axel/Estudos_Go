# 📘 Estudos de Go — Roteiro

Material de estudo da linguagem **Go (Golang)**, organizado em módulos progressivos.
Cada módulo é uma pasta com arquivos `.md` curtos, cheios de exemplos e exercícios.

> 💡 **Como estudar:** leia o arquivo, **digite** os exemplos (não copie e cole!), rode com `go run` e faça os exercícios no final de cada arquivo.
